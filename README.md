# FOODWISE AI – AI Problem Design

## SWYNEX Internship – Task 1

### Project Overview
FOODWISE AI is a food-related project designed to help users explore suitable meal options based on available ingredients and personal preferences.

### Problem Statement
People sometimes struggle to decide what meals to prepare using the ingredients they have available.

### Proposed Solution
FOODWISE AI aims to help users discover suitable food options using food-related information and recommendations.

### Target Users
- Students
- Working professionals
- People interested in food and nutrition
- People who want to use available ingredients efficiently

### Task Objectives
- Identify a real-world problem.
- Understand target users.
- Identify suitable data sources.
- Select an appropriate AI approach.
- Define limitations and evaluation criteria.
